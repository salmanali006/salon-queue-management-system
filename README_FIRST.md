# Salon Queue Management System — Codex project package

Start here:

1. Read `CODEX_SETUP.md`.
2. Open this whole folder as the active Codex project.
3. Check that `AGENTS.md` is present at the project root.

5. After reviewing the discovery plan, run the remaining prompts one by one.

The authoritative requirements are in `docs/01-brief.md`, `docs/02-screens.md` and `docs/03-flows-rules.md`.
